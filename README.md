# RentRelay

RentRelay is a ServiceNow application being developed to help tenants, property managers, and repair professionals coordinate rental inspections and maintenance. It brings inspection records, repair requests, photos, work updates, and actual repair costs together to support maintenance and spending decisions.

## Project Status

In development. The features below describe the planned application. Availability will depend on implementation, testing, and the ServiceNow capabilities available to the team.

## Planned Features

- Move-in inspections with condition notes and original photos.
- Repair requests with issue descriptions, photos, and access permission.
- Safety screening and escalation for urgent issues.
- A repair professional directory organized by specialty, service area, and availability.
- Manager review, priority confirmation, and repair assignments.
- Progress updates and before-and-after repair photos.
- Completion records with work performed, labor, parts, and actual costs.
- Tenant confirmation and reopening of unresolved repairs.
- Equipment repair history and maintenance dashboards.
- Role-based access for tenants, managers, and repair professionals.

Later development includes AI-assisted inspection review, repair intake suggestions, Ask RentRelay questions and answers, and maintenance spending estimates. AI suggestions will require appropriate human review.

## Sprint Plan

| Sprint | Focus |
|---|---|
| Sprint 1 | User access, property and equipment records, inspections, photo uploads, and repair requests |
| Sprint 2 | Safety screening, provider directory, assignments, progress updates, completion, and notifications |
| Sprint 3 | Maintenance dashboards, equipment history, spending summaries, testing, and user instructions |
| Later sprint | AI assistance and spending estimates |

## ServiceNow Setup

Running RentRelay requires a ServiceNow instance with the necessary application permissions and capabilities. Forking this repository copies the project files; it does not create or copy a ServiceNow instance.

Application import instructions and required dependencies will be documented as the build progresses.
